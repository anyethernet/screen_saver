## English

Webcam & Screen Saver does not create developer accounts for users. Camera video travels only between the home phone and the viewing device, over Tailscale or an address you open yourself. The developer does **not** store video, accounts, or location history on developer servers.

**Camera permission** is used only when this phone is the home camera.  
**Network permission** is used to send and receive video.  
**Nearby device discovery** is used to find devices on the same home network so they can be turned on or off.

If you use Tailscale, sign-in and VPN connection stay in the Tailscale app and follow [Tailscale’s policies](https://tailscale.com/privacy-policy).

To stop using the app, uninstall it. The developer does not keep separate copies of your video.

Windows screensaver software for this project may be distributed from the project’s GitHub Releases page when available.

## 한국어

웹캠 & 화면 보호기는 개발사 사용자 계정을 만들지 않습니다. 카메라 영상은 Tailscale 또는 사용자가 연 집 주소로, 집 폰과 보는 기기 사이에서만 이동합니다. 개발사 서버에 영상, 계정, 위치 기록을 올리지 않습니다.

**카메라 권한**은 이 폰을 집 카메라로 쓸 때만 사용합니다.  
**네트워크 권한**은 영상을 보내고 받기 위해 사용합니다.  
**근처 기기 찾기**는 같은 집 네트워크에서 켜고 끌 기기를 찾기 위해 사용합니다.

Tailscale을 쓰는 경우 로그인과 연결은 Tailscale 앱의 계정으로 이루어지며, 그 계정 정보는 [Tailscale 개인정보처리방침](https://tailscale.com/privacy-policy)에 따릅니다.

사용을 멈추면 앱을 삭제하면 됩니다. 개발사 쪽에 별도로 보관된 사용자 영상은 없습니다.

Windows용 화면 보호기 설치 파일은 GitHub Releases에서 제공할 수 있습니다(저장소·릴리스 공개 설정에 따름).
